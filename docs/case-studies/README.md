## Format Expectations

Every case study should include:
1. **Executive summary** (metrics + highlights)
2. **Narrative arc** (challenge → crisis → resolution)
3. **Technical deep dive** (files, commits, diagnostics)
4. **Evidence** (logs, probes, metrics tables)
5. **Key learnings & frameworks**
6. **Business impact** (velocity, reliability, savings)
7. **Implementation guide / checklist**

## Contributing
