# Landing Experience Brief
MetaCurtis Consciousness Theater
Phase 2: Experience Design

## Core idea

The landing page should not simply show FORM inside particles.

It should feel like:

**an intelligent atmospheric field hiding meaning, then revealing it, then turning that meaning into interface.**

The hero is not only a visual.
It is the narrative and interaction anchor of the page.

## Experience goal

The user should feel:

1. curiosity
2. discovery
3. depth
4. authority
5. system-level intelligence

The emotional shift should be:

**hidden intelligence -> discovered structure -> revealed depth -> interface emergence**

## Final Phase 2 experience

### Phase 1 - Invisible Intelligence
The page opens on visible atmospheric mist.

Requirements:
- mist must be visible above black
- no explicit FORM yet
- field must feel alive, layered, and intelligent
- no decorative symbol cloud

The user should feel:
"something is here"

### Phase 2 - Discovery
As the user scrolls, FORM is discovered inside the mist.

Requirements:
- FORM should emerge from the field, not appear as a separate object
- reveal should feel inevitable
- the field should still remain present
- discovery must be readable without becoming blunt or obvious

The user should feel:
"it was hidden inside the atmosphere"

### Phase 3 - Depth Revelation
Once FORM is established, waves/currents reveal topography and depth around it.

Requirements:
- mist should move in layered currents
- the waves should reveal depth, not obscure the word
- FORM should remain stable while the field continues to live around it
- the field should feel like an atmospheric lens rather than a decorative background

The user should feel:
"the word is alive inside a structured environment"

### Phase 4 - UI Integration / Peel
The UI should emerge in concert with FORM and scroll.

Requirements:
- UI should not feel like a separate overlay dropped on top
- peel/navigation response should feel born from the same system
- scroll should be the organizing force
- FORM and UI should feel related, not competing layers

The user should feel:
"the visual system became the interface"

## Visual doctrine for Phase 2

### Mist
Mist should be:
- visible
- layered
- soft
- structured
- luxurious
- subordinate to meaning

Mist should not be:
- invisible
- noisy
- iconographic
- sparkly
- stronger than FORM

### FORM
FORM should be:
- readable
- stable
- sovereign
- dimensional
- connected to the field

FORM should not be:
- a glowing slab
- a disconnected logo
- swallowed by atmosphere

### Waves / atmospheric bands
The wave system should:
- reveal depth
- reveal structure
- imply environmental intelligence
- move more than FORM
- stay subtle enough to preserve hierarchy

It should not:
- act like water simulation
- wobble the word
- turn the hero into an effect demo

## What success looks like

A successful Phase 2 landing experience will make a visitor feel that:

- the hero contains hidden intelligence
- the word FORM is discovered, not shown
- the atmosphere remains alive after the reveal
- the visual system itself is the beginning of the interface
- the page feels premium and authored, not template-based

## What Phase 2 is not

Phase 2 is not:
- another particle-debugging phase
- an atlas-redesign phase
- a shader-experiment for its own sake
- a generic animation polish task

Phase 2 is:
**experience orchestration**
