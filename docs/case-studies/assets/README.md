# Case Study Assets

Supporting materials used by the narratives in `docs/case-studies/`.

## Structure

```
assets/
├── pattern-s-refactor/
│   ├── METRICS.md
│   ├── architecture-diagrams/ (reserved)
│   ├── metrics/ (reserved)
│   └── code-samples/ (reserved)
└── future-case-studies/
```

## Pattern S Refactor

- `METRICS.md` – quantitative summary (velocity, quality, business metrics)
- `architecture-diagrams/` – (slot for layer stack + BeatBus topology)
- `code-samples/` – (slot for probes, guards, ownership snippets)

When authoring a new case study, create a sibling directory (e.g., `assets/<case-name>/`) and reference artifacts from the main document.
