# Buyer Profile Map

## Design-forward startup
- Needs: premium differentiation + conversion surface
- Fit: Package A or B

## AI-native product team
- Needs: distinctive launch surface with measurable UX behavior
- Fit: Package B

## Founder/personal brand
- Needs: high-end signature hero with clear CTA anchoring
- Fit: Package A

## Agency / studio partner
- Needs: white-label implementation and repeatability
- Fit: Package C

## Enterprise innovation/brand team
- Needs: controlled wow-factor with governance
- Fit: Package B or C

## Qualification signals
- Wants deterministic validation (not subjective-only iteration)
- Accepts bounded change governance
- Needs UI-capable visual surface, not only motion art
