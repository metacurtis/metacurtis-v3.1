# Commercial Spec Pack — Velocity Landing Slice (RC1)

## Product
Velocity Landing Slice (RC1)

## Positioning
A premium interactive word-formation hero slice for landing pages, validated with deterministic diagnostics and release-gate checks.

## Offer tiers

### Tier 1 — Hero Slice Sprint
- One word/preset delivery on approved brand palette
- RC baseline setup, validation run, artifact pack
- 2 revision rounds (composition-level)
- Delivery window: 5-7 business days after assets

### Tier 2 — Landing System
- Hero Slice Sprint scope
- 2 additional variants (palette and motion personality)
- UI-anchor ready contract and integration notes
- 3 revision rounds total
- Delivery window: 10-14 business days after assets

### Tier 3 — Ongoing Motion Retainer
- Monthly iterative tuning and variant production
- Contract-driven diagnostics and release-gate checks per variant
- Priority queue and monthly review cadence
- 1-2 slices/month typical throughput

## Deliverables (standard)
- runtime config changeset
- validation artifacts: probe/screens/contact sheet
- scenario summary and gate status
- handoff runbook with safe-change policy

## Exclusions (unless scoped)
- full site implementation
- backend/content platform integration
- multi-language typographic QA
- analytics instrumentation

## Client inputs required
- final word(s)
- brand palette and fallback colors
- typography constraints (if any)
- deployment target (Framer/Webflow/custom React)
- acceptance deadline and stakeholders

## Revision policy
- Revisions apply to scoped visual behavior only
- Architecture changes require explicit change order
- Any requested change that breaks gate PASS must be remediated before acceptance

## Acceptance criteria
- release gate PASS
- no schema violations
- no single-writer violations
- artifacts delivered and reproducible from runbook

## Pricing model (template)
- Sprint: fixed fee
- System: fixed fee + option add-ons
- Retainer: monthly fee with defined throughput

## Deployment options
- Embedded React implementation
- Framer/Webflow host integration bridge
- Standalone preview + handoff package
