# Landing Baseline Summary
MetaCurtis Consciousness Theater
Phase 1 closeout: FORM + mist baseline

## Baseline status

This baseline represents the end of the first major landing-slice phase.

The system now achieves the following:

- FORM is readable and visually dominant during lock and drift.
- The atmospheric field reads as mist rather than symbolic particle iconography.
- The atlas ontology has been corrected for the live landing path.
- Carrier authority is authored upstream and no longer inferred only from tier or glyph-zone heuristics.
- Non-carrier high-tier particles have been suppressed enough to stop competing strongly with FORM.
- Fragment polish restored enough atmospheric body that the field remains present on black without collapsing into bloom sludge.
- Tier 0 / Tier 1 atmospheric motion now supports slow structured flow rather than random drift.

## What is solved

### 1. FORM anchor readability
FORM is now readable at the key lock/drift checkpoints and no longer collapses into a soft slab or disappears into the field.

### 2. Atmospheric ontology
The field no longer reads primarily as stars, rings, mandalas, or symbolic shapes. It reads as mist/density first.

### 3. Carrier authority
True FORM carriers are authored upstream via `formWeight`, and non-carrier particles no longer inherit too much authority from tier alone.

### 4. Mist support
The field remains present and atmospheric in the final state rather than vanishing completely behind the word.

## What remains unresolved

This baseline is strong enough to freeze, but it is not the final experience.

Remaining gaps are now primarily in the experience layer:

- The mist is still more perceptually subtle than ideal during discovery.
- The reveal sequence is not yet staged as a strong narrative experience.
- The relationship between scroll, reveal, wave/topography, and UI peel has not been fully designed.
- The page around the hero is not yet integrated.

## What must be preserved

The following are now treated as working baseline truths and should not be casually reopened:

- single-writer renderer ownership
- stage-mode landing path
- corrected live atlas routing
- corrected atlas ontology
- authored `formWeight`
- non-carrier suppression seam in stage build
- current FORM readability baseline
- deterministic validation workflow
- probe + screenshot capture workflow

## Baseline judgment

This baseline is good enough to freeze and use as the starting point for the next phase.

The next phase is not "fix the particle system again."

The next phase is:

**design and implement the landing experience**
where
- mist is visible before FORM,
- FORM is discovered through scroll,
- waves reveal depth,
- UI emerges through the same visual system.

## Primary rule for Phase 2

Do not reopen Phase 1 architecture unless a Phase 2 ZAG pass proves it is necessary.

Phase 2 should focus on:
- reveal choreography
- perceptual mist visibility
- scroll staging
- wave/topography behavior
- UI integration
